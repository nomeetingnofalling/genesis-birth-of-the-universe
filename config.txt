# CONFIG — параметры панели управления (birth_processing / index.html)
#
# Каждый контрол — это HTML-слайдер (или переключатель), который в коде
# читается функцией readControl() как «сырое» число (0–100, у «скорости
# движения» 0–200) и затем нормируется в 0..1, после чего пересчитывается
# в физическое/визуальное значение по формуле, указанной в поле "формула".
#
#   ползунок   — диапазон самого HTML-инпута (то, что двигает пользователь)
#   min (0%)   — абсолютное значение эффекта, когда ползунок в крайнем левом
#                положении (raw = 0)
#   max (100%) — абсолютное значение эффекта, когда ползунок в крайнем правом
#                положении (raw = 100, у «скорости движения» raw = 200)
#   default    — значение по умолчанию при запуске страницы: сырое положение
#                ползунка → эффективное (абсолютное) значение на этом положении
#   описание   — что делает контрол, как работает, на что влияет (≤500 симв.)
#
# Значения default ниже — рабочая точка из приложенного скриншота панели
# (23:03, все планеты и звёзды приглушены, слова текут широким плотным
# потоком). Контролы из групп «звук» (громкость/частота/дилей), «присутствие»
# и MIDI на скриншоте не видны — их default оставлен как в коде (без
# изменений), это отмечено отдельно.


## ГРУППА: ЖИЗНЬ (движение и вид облака точек, из которых состоят слова)

[плотность точек] id=density
  ползунок: 0–100
  min (0%):   0.10  — видно 10% точек слова
  max (100%): 1.00  — видно 100% точек слова
  default: 21 → 0.289 (≈29% точек)
  формула: 0.1 + 0.9*(raw/100)
  описание: Доля точек каждого слова, которая реально отрисовывается и
  участвует в движении (остальные точки существуют, но скрыты). Меньше
  значение — облако выглядит разреженным и «пылевым», больше — слово читается
  плотным и цельным. Точки отбираются по случайному рангу, поэтому при любом
  значении форма слова сохраняется, просто гуще или реже засеяна.

[скорость движения] id=speed
  ползунок: 0–200 (единственный слайдер с диапазоном шире 0–100)
  min (0%):   0.0  — точки полностью замирают
  max (100%): 2.0  — двойная скорость течения/полёта точек
  default: 189 → 1.89x (почти удвоенная скорость)
  формула: raw/100 (множитель скорости, при raw=100 → 1.0x — «обычная» скорость)
  описание: Общий множитель скорости всех перемещений точек — течения по
  полю, вихря, сферы, притяжения к дому. При 0 всё замирает статичным кадром,
  при 100 — нормальный «родной» темп анимации, выше 100 — ускоренный,
  нервный поток. Не влияет на звёзды и планеты — только на точки слов.

[вихрь] id=vortex
  ползунок: 0–100
  min (0%):   0.00 — точки следуют только базовому потоку поля
  max (100%): 1.00 — движение точек полностью подчинено вихревой орбите
  default: 0 → 0.00 (вихрь выключен)
  формула: raw/100 (доля подмеса вихревой скорости через lerp)
  описание: Подмешивает к обычному течению вращательное орбитальное движение
  вокруг центра (по фигуре восьмёрки/лемнискаты). 0 — вихря нет, точки текут
  как обычно; 100 — точки почти полностью закручиваются в вихрь вокруг
  центра экрана. Хорошо заметен вместе со «скоростью движения».

[сфера] id=sphere
  ползунок: 0–100
  min (0%):   0.00 — сферическая орбита не используется; радиус сферы 60px
  max (100%): 1.00 — движение полностью на сфере; радиус сферы 520px
  default: 0 → 0.00 (эффект выключен)
  формула: raw/100; радиус сферы = lerp(60, 520, raw/100) px
  описание: Стягивает точки на поверхность воображаемой вращающейся сферы
  вместо плоского движения. При 0 эффект отсутствует. При росте значения
  точки всё сильнее «прилипают» к сфере растущего радиуса (от 60 до 520px) и
  вращаются по её поверхности вместо обычного течения по полю.

[удаленность] id=distance
  ползунок: 0–100
  min (0%):   10% диагонали экрана — точки держатся у центра
  max (100%): 80% диагонали экрана — точки могут разлетаться далеко к краям
  default: 18 → ~19.4% диагонали (близко к центру)
  формула: maxSpread = lerp(диагональ*0.10, диагональ*0.80, raw/100)
  описание: Максимальное расстояние, на которое точки могут «убегать» от
  центра слова, в долях диагонали экрана. Маленькое значение держит слова
  компактными в центре кадра; большое — позволяет облаку точек растекаться
  почти по всему экрану.

[связность] id=cohesion
  ползунок: 0–100
  min (0%):   0.00 — точки не тянет обратно к своему слову
  max (100%): 1.00 — максимальная сила притяжения к «дому» точки
  default: 37 → 0.37
  формула: raw/100; сила пружины = min(расстояние*0.03, 1.6) * значение
  описание: Сила «пружины», которая тянет каждую точку обратно к исходному
  месту в своём слове. При 0 точки могут уплывать сколь угодно далеко (пока
  их не ограничит «удалённость»/поле); при высоких значениях слово стремится
  удержать форму и не рассыпаться, даже когда включены вихрь или сфера.

[количество линий] id=links
  ползунок: 0–100
  min (0%):   0% точек соединяются линиями
  max (100%): 22% точек соединяются линиями (жёсткий потолок LINK_MAX_SHARE)
  default: 91 → 20.0% точек
  формула: (raw/100) * 0.22 — доля точек, которым разрешено рисовать линию
  описание: Доля точек, между которыми (и соседними точками поля) рисуются
  тонкие соединительные линии — эффект «созвездия»/сетки. Максимум сознательно
  ограничен 22% точек даже на 100, чтобы сетка линий не превращалась в сплошной
  клубок и не забивала картинку.

[свечение] id=glow
  ползунок: 0–100
  min (0%):   гало выключено (радиус 2.88px, альфа-множитель 0)
  max (100%): радиус гало 10px, альфа-множитель на максимуме
  default: 92 → 0.92 (почти максимальное свечение)
  формула: raw/100; радиус = lerp(2.88, 10, значение) px; альфа = a*значение*(0.18 или 0.32 во вспышке)
  описание: Интенсивность и радиус мягкого светящегося ореола вокруг каждой
  точки. При 0 точки рисуются «сухими», без сияния; при 100 вокруг каждой
  точки — заметный мягкий световой ореол, особенно яркий у «вспыхивающих»
  точек. Главный параметр «воздушности»/свечения всей картинки.

[шлейф] id=trail
  ползунок: 0–100
  min (0%):   0px хвост, альфа-множитель 0
  max (100%): 72px хвост, альфа-множитель 0.42
  default: 25 → 0.25
  формула: raw/100; длина хвоста = 72*значение px; альфа = значение*0.42; толщина линии хвоста растёт с значением
  описание: Длина и заметность светового следа («хвоста»), который тянется
  за каждой движущейся точкой. При 0 точки не оставляют следа; чем выше
  значение, тем длиннее и ярче хвост позади движения — создаёт ощущение
  скорости и текучести, особенно заметно вместе с высокой «скоростью движения».

[HSB облака] id=hsbWheel (не слайдер — круговой 2D-виджет: оттенок + насыщенность)
  диапазон: оттенок (угол) 0–360°, насыщенность (радиус) 0–100%
  min: нет крайнего «0/100» как у слайдера — это точка на цветовом круге
  max: —
  default (в коде, не показан числом на скриншоте): оттенок 17°, насыщенность 68%
  формула: цвет подмеса = HSB(оттенок, насыщенность, 100%); угол = оттенок-90°, радиус точки = насыщенность/100*18px
  описание: Круглый цветовой пикер — выбирает оттенок и насыщенность цвета,
  в который подмешивается свечение облака точек (см. «чувствительность HSB»
  ниже, которая задаёт силу этого подмеса). Положение точки на скриншоте
  явно не считывается (виджет мелкий, без цифр), поэтому оставлено текущее
  значение по коду: оттенок 17°, насыщенность 68%.

[чувствительность HSB] id=hsbMix
  ползунок: 0–100
  min (0%):   0.00 — цвета точек не подмешиваются к выбранному HSB-оттенку
  max (100%): 1.00 — цвета точек полностью заменены выбранным HSB-оттенком
  default: 10 → 0.10 (лёгкий подмес)
  формула: raw/100 (cloudMixAmount — доля подмеса выбранного цвета)
  описание: Насколько сильно родные цвета облака точек подмешиваются к
  цвету, выбранному на круговом HSB-пикере выше. При 0 палитра точек
  полностью «родная»; при высоких значениях весь спектр стягивается к одному
  выбранному оттенку. Спрайт подмеса пересчитывается только когда значение
  выше ~0.3, чтобы не тратить кадры зря на малозаметный эффект.


## ГРУППА: ЗВЁЗДЫ (фоновое поле пролетающих звёзд, режим «полёт вперёд»)

[звёзды вкл] id=starEnabled (чекбокс, не слайдер)
  значения: включено / выключено
  default: выключено (было включено по коду; на скриншоте чекбокс пуст)
  описание: Полностью включает или выключает отрисовку звёздного поля.
  Выключено — звёзды не рисуются вовсе (остальные звёздные слайдеры не
  действуют, пока не включено). Включено — работает фон из 240 пролетающих
  звёзд с хвостами, управляемый слайдерами ниже.

[скорость звёзд] id=starSpeed
  ползунок: 0–100
  min (0%):   скорость полёта x1 (900px/с база), хвост не подтягивается к центру (0%)
  max (100%): скорость полёта x10 (9000px/с база), хвост подтянут к центру на 100%
  default: 17 → 0.17 (≈2.5x базовой скорости, лёгкое подтягивание хвоста)
  формула: множитель скорости = lerp(1,10,значение) (дополнительно умножается на «движение вперёд»); доля подтяжки хвоста к центру = значение
  описание: Двойной эффект: (1) насколько быстро звёзды летят на зрителя —
  от обычной скорости до десятикратной, и (2) насколько сильно их световой
  хвост «стягивается» к центру экрана вместо обычного растяжения назад по
  направлению полёта. Итоговая скорость дополнительно умножается на
  «движение вперёд».

[контраст звёзд] id=starContrast
  ползунок: 0–100
  min (0%):   контраст x1 (обычный)
  max (100%): контраст x2 (удвоенный)
  default: 100 → 2.0x (максимальный контраст)
  формула: lerp(1, 2, значение)
  описание: Множитель контраста между яркими и тусклыми звёздами. При 0
  все звёзды выглядят близко по яркости; при 100 разница между самыми
  яркими и самыми тусклыми звёздами в поле удваивается — звёзды у линии
  горизонта полёта выглядят заметно ярче фоновых.

[яркость звёзд] id=starBrightness
  ползунок: 0–100
  min (0%):   альфа тусклых звёзд = 36 (из 255) — почти невидимы
  max (100%): альфа тусклых звёзд = 255 — полностью непрозрачны
  default: 0 → альфа 36 (тусклые звёзды почти не видны)
  формула: lerp(36, 255, значение)
  описание: Базовая непрозрачность (альфа-канал) самых тусклых звёзд в поле.
  При 0 дальние/тусклые звёзды почти сливаются с фоном, видны в основном
  яркие; при 100 даже тусклые звёзды рисуются полностью непрозрачными —
  всё звёздное поле выглядит гуще и заметнее.

[вращение звёзд] id=starSpin
  ползунок: 0–100
  min (0%):   0 рад/с — звёздное поле не вращается
  max (100%): ≈4.19 рад/с (~0.667 оборота/с, полный оборот за ~1.5с)
  default: 0 → 0 рад/с (вращение выключено)
  формула: STAR_SPIN_MAX_SPEED * значение, где STAR_SPIN_MAX_SPEED = (2π/15)*10
  описание: Скорость вращения всего звёздного поля вокруг центральной оси
  обзора (как штурвал корабля). При 0 звёзды летят строго по прямой на
  зрителя; при 100 всё поле дополнительно закручивается вокруг центра с
  периодом чуть больше секунды на полный оборот.

[движение вперёд] id=starForward
  ползунок: 0–100
  min (0%):   доп. множитель скорости x1 (без ускорения)
  max (100%): доп. множитель скорости x2
  default: 0 → x1 (без доп. ускорения)
  формула: lerp(1, 2, значение) — умножается на скорость из «скорость звёзд»
  описание: Дополнительный форсаж скорости полёта звёзд поверх «скорости
  звёзд» — до двукратного ускорения. Используется, чтобы усилить ощущение
  рывка вперёд, не трогая при этом длину подтяжки хвоста, которую задаёт
  отдельно «скорость звёзд».


## ГРУППА: СИНЯЯ ПЛАНЕТА / КРАСНАЯ ПЛАНЕТА
## (у обеих планет одинаковые формулы; красная planet2 — вторая, дальняя,
## её орбита в 1.524 раза больше синей — соотношение орбит Марс/Земля)

[масса планеты] id=planetMass / id=planet2Mass
  ползунок: 0–100
  min (0%):   отношение массы 5x (от базовой массы Луны); радиус на экране 3px
  max (100%): отношение массы ≈38 695x; радиус на экране 9.3px
  default: 0 → масса 5x, радиус 3px (планета минимального размера и притяжения)
  формула: массаОтношение = (масса Сатурна/масса Луны)^значение * 5; радиусPx = lerp(3, 9.3, √значение)
  описание: Насколько «тяжёлая» и большая планета. Влияет на силу
  гравитационного притяжения, которое планета оказывает на точки облака
  (через 1/расстояние²), и на видимый радиус планеты на экране. При 0
  планета минимальна и почти не притягивает точки; к 100 масса растёт
  экспоненциально и притяжение становится доминирующей силой в сцене.

[скорость вращения] id=planetSpeed / id=planet2Speed
  ползунок: 0–100
  min (0%):   период обращения по орбите 42с (медленно)
  max (100%): период обращения по орбите 0.42с (очень быстро, x100)
  default: 0 → период 42с (самое медленное вращение)
  формула: множитель = lerp(1,100,значение); угловая скорость = (2π/42с)*множитель
  описание: Скорость, с которой планета обращается вокруг центра сцены. При
  0 — один оборот занимает 42 секунды, почти статично; к 100 планета
  проносится по орбите за доли секунды. Не влияет на форму орбиты — только
  на то, как быстро планета по ней движется.

[орбита] id=planetDistance / id=planet2Distance
  ползунок: 0–100
  min (0%):   отношение дистанции 1x; орбита синей 230×95px (красной 350.5×144.8px)
  max (100%): отношение дистанции 100x; орбита синей 920×380px (красной 1402×579px, x4 от базовой)
  default: синяя 23 → ~20% раздутия орбиты; красная 21 → ~18% раздутия орбиты
  формула: дистанцияОтношение = lerp(1,100,значение) (ослабляет притяжение как 1/дист²); rx/ry = lerp(база, база*4, значение)
  описание: Насколько широкая у планеты орбита (в пикселях эллипса на
  экране) и, отдельно, насколько ослаблено гравитационное притяжение
  планеты на дальней орбите (по закону обратных квадратов). При 0 орбита
  компактная и притяжение сильнее при той же массе; при 100 орбита
  почти вчетверо шире базовой, а притяжение на такой дистанции слабее.


## ГРУППА: ТОЧКА ВРАЩЕНИЯ (центральное «солнце»)

[притяжение] id=sunAttraction
  ползунок: 0–100
  min (0%):   отношение массы 0 (солнце не притягивает, невидимо как источник массы); радиус на экране 4px
  max (100%): отношение массы ≈27 091 000x (от массы Луны); радиус на экране 14px
  default: 0 → притяжение выключено, радиус 4px
  формула: массаОтношение = значение*(масса Солнца/масса Луны); радиусPx = lerp(4, 14, значение)
  описание: Сила притяжения центральной «звезды» сцены (рисуется как
  светящаяся точка в центре экрана) и её видимый размер. При 0 эффект
  полностью выключен — центрального притяжения нет; при росте значения
  появляется и усиливается гравитационный «якорь» в центре, к которому
  притягиваются точки облака, а сама точка-солнце становится крупнее и ярче.


## ГРУППА: ЗВУК (звуковые «колокольчики» при столкновениях/событиях)
## Не видны на приложенном скриншоте — значения оставлены как в коде,
## без изменений.

[звук: вкл/выкл] id=soundToggle (кнопка-переключатель, не слайдер)
  default: выключено (совпадает со скриншотом — уже было выключено)
  описание: Общий выключатель звукового вывода. Пока выключено, слайдеры
  «громкость/частота/дилей» ни на что не влияют — движок звука не издаёт
  колокольчиков вовсе.

[громкость] id=volume
  ползунок: 0–100
  min (0%):   пиковая громкость колокольчика = 0
  max (100%): пиковая громкость колокольчика = 0.07 (условные единицы gain)
  default: 50 → 0.50 (не изменено, не видно на скриншоте)
  формула: peak = 0.07 * loud * значение, где loud зависит от силы столкновения
  описание: Множитель громкости звуковых «колокольчиков», которые звучат при
  событиях сцены (столкновения точек и т.п.). 0 — беззвучно, 100 — полная
  громкость эффекта колокола (в рамках базового пика 0.07).

[частота] id=frequency
  ползунок: 0–100
  min (0%):   базовая частота тона 100 Гц
  max (100%): базовая частота тона 800 Гц
  default: 15 → ~181 Гц (не изменено, не видно на скриншоте)
  формула: baseFreq = 100 * (800/100)^значение — экспоненциальная интерполяция
  описание: Высота (частота) звуковых колокольчиков. Низкое значение — низкий
  гулкий тон около 100 Гц; высокое — звонкий высокий тон около 800 Гц.
  Интерполяция экспоненциальная, а не линейная, чтобы шаг звучал музыкально
  равномерно по всей шкале.

[дилей] id=delay
  ползунок: 0–100
  min (0%):   эффект дилея выключен (wet=0, feedback=0)
  max (100%): wet=0.5, feedback=0.45 (заметное эхо с повторами)
  default: 60 → wet 0.3, feedback ~0.35 (не изменено, не видно на скриншоте)
  формула: wet = значение*0.5; feedback = значение>0 ? 0.2+значение*0.25 : 0
  описание: Сила эффекта эхо/дилея на звуковых колокольчиках — насколько
  громко и насколько долго звук повторяется затухающим эхом. При 0 колокол
  звучит один раз без повторов; при 100 звук заметно «расходится» эхом с
  повторами и обратной связью.


## ГРУППА: ПРИСУТСТВИЕ (реакция сцены на звук с микрофона)
## Не видна на приложенном скриншоте — значения оставлены как в коде,
## без изменений.

[чувствительность] id=presence
  ползунок: 0–100
  min (0%):   усиление вибрации от звука микрофона x1 (без буста)
  max (100%): усиление вибрации от звука микрофона x4
  default: 0 → x1 (буст выключен, не изменено, не видно на скриншоте)
  формула: boost = 1 + значение*3
  описание: Насколько сильно громкость звука с микрофона «трясёт» облако
  точек (см. кнопку «микрофон» ниже, включающую сам захват звука). При 0
  реакция на звук минимальна; при 100 даже негромкий звук с микрофона
  вызывает заметную вибрацию точек.

[микрофон: вкл/выкл] id=presenceToggle (кнопка-переключатель, не слайдер)
  default: выключено (не изменено, не видно на скриншоте)
  описание: Включает/выключает захват звука с микрофона для эффекта
  «присутствия» выше. Пока выключено, слайдер «чувствительность» ни на что
  не влияет — микрофон не слушается вовсе.
