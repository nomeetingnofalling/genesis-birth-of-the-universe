# Genesis — Birth of the Universe

Живая генеративная сцена на p5.js: облако точек рождается из света,
излучённого центральной точкой, и живёт своей жизнью — плывёт по шумовому
полю, закручивается вихрем, притягивается к планетам и к центральной
точке вращения, вибрирует в такт звуку с микрофона.

**Открыть:** [живая версия](https://ТВОЙ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/)
— замени ссылку на свою после публикации через GitHub Pages.

## Что на экране

- **Вступление.** Из центральной точки расходятся прозрачные светящиеся
  лучи, свечение медленно вращается, лучи растворяются в ореоле из пяти
  цветов; ореол медленно растёт, заливает весь экран и тает (время
  растворения — `introDissolve` в `config.txt`: 0% = 1 мин, 100% = 10 мин,
  по умолчанию 30%). Из свечения в том же темпе понемногу проявляются точки — сначала
  ближние к центру (синие, зелёные), потом дальние (светлые, красные,
  жёлтые). Цвет каждой точки взят из того места свечения, где она
  родилась.
- **Сцена.** Точки собраны в облако, двигаются по вихревому полю, у
  каждой — своё колебание и своя глубина. Столкновения настоящие:
  точки отскакивают друг от друга и на мгновение вспыхивают.
- **Небо.** Звёздное поле с перспективой — сквозь него летит камера,
  звёзды вытягиваются в хвосты по скорости полёта.
- **Планеты.** Синяя и красная — на своих орбитах вокруг центра,
  притягивают точки к себе. Масса, скорость, орбита — на ползунках.
- **Точка вращения.** Неподвижное «солнце» в центре, его притяжение
  держит всё вокруг, когда выкручено.
- **Микрофон.** Громкость звука заставляет точки мелко дрожать в такт,
  а в углу экрана колышется волна-индикатор.
- **Звук.** При столкновениях точек звенит хрусталь — чистый Web Audio,
  шесть голосов, дилей.

## Как открыть

**Просто посмотреть:** скачай `index.html` и открой двойным кликом в
браузере. Всё работает без сервера, внешних файлов нет.

**Публично:** залей в GitHub и включи GitHub Pages (см. ниже).

## Управление

Все ползунки — в панели слева, выезжает кнопкой **☰** в левом верхнем
углу. Рядом с каждым — живое значение. Кнопка **«Хаос»** внизу панели
случайно раскидывает все ползунки визуализации — хороший способ найти
неожиданный кадр.

**Микрофон** включается кнопкой в блоке «присутствие» (браузер
спросит разрешение). **Звук** включается отдельной кнопкой в блоке
«звук». Обе кнопки независимы: можно слушать микрофон без звука на
выходе, и наоборот.

## Технически

- Один файл `index.html` — вся разметка, стили и код внутри.
- p5.js 1.11.13 с CDN, других внешних зависимостей нет.
- Канвас 1280×720, 30 fps, растягивается с сохранением пропорций.
- Случайность сидированная (`randomSeed(7)`, `noiseSeed(7)`) — при
  одном и том же наборе настроек картинка воспроизводима.
- Точки (шлейф, свечение, ядро) и линии связи рисует видеокарта через
  WebGL-слой поверх p5-канвы — одним вызовом на кадр, поэтому 30 fps
  держатся и на максимальной плотности. Если WebGL недоступен, включается
  прежняя отрисовка спрайтами (32 оттенка из радуги вступления).
- В правом верхнем углу — средний FPS, чёткость слоя точек и способ
  отрисовки (`GL` — видеокарта, `2D` — запасной путь).
- Звёздное поле прореживается и обрезается за границами холста на
  высокой скорости — 240 звёзд не превращаются в кашу.
